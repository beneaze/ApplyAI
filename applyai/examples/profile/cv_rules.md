# My CV rules

Personal rules every tailored CV follows, on top of ApplyAI's built-in ones (truth only, one
page, posting keywords, 3-letter months). Write them as plain sentences. Examples:

- Keep the current job first in Work Experience, with at least one bullet, on every CV.
- Keep the Skills row "Languages & German (Native), English (Fluent)" exactly as written.
- Never mention grades below 2.0.
- Write locations as "City, Country", never US state abbreviations.
